# Publicaciones

Este directorio contiene los archivos finales de cada publicación, organizados por colección.

Estructura sugerida:
- historia/
- territorio/
- gente/
- descubrir/
- cultura/
- archivo/

Cada publicación puede tener su propia carpeta con PDF, imágenes y material complementario. Los archivos no aparecerán en el catálogo hasta que se agregue su ficha a `js/catalogo.js` con `status: "published"`.

No subir materiales de terceros sin comprobar permisos de reproducción y descarga.
